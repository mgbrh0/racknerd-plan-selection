**不退款。** 官方服务条款写得很直接：任何产品都不支持退款，没有 30 天无理由那一套。你中途取消服务，系统做的是停机、删数据，钱不回来。这一条在低价 VPS 圈不算罕见，但它决定了你第一次下单应该小额试水，而不是一上来锁三年付。

## 注册账号：卡住大多数人的是那个验证码

注册入口在官网右上角 **My Account** → **Register**。要填的东西不多：邮箱、密码、姓名、地址、电话。地址别乱编，国家和省份至少要写对，后面开工单、核对账单都要对得上。

提交时会弹 Google reCAPTCHA。这一步是国内用户注册 RackNerd 最容易失败的地方：网络访问 Google 不稳定的时候，验证码框根本加载不出来，点提交没有反应，或者转圈转到超时。有教程作者提到自己在这一步卡了半小时，换了好几个节点才过。处理办法就两个——挂代理后刷新页面重试，或者换一个能正常访问 Google 的网络环境。提前把这一关过掉，后面一路通畅。

验证通过后去邮箱点激活链接，账号才算建好。

顺便说一句：网上有些教程会让你在注册时填"邀请码"，官网流程里没有这个东西，跳过。

## 付款：支付宝这条路走一遍就熟了

结算页先确认账户信息，第一次下单会在这里补完注册时没填的资料，然后选支付方式。

RackNerd 支持的付款方式比较全：信用卡（VISA / Master / AMEX / Discover）、PayPal、支付宝、银联、加密货币（BTC / BCH / LTC / ETH / USDT / USDC）、银行转账。国内用户最顺的是支付宝。

流程是这样：

1. 支付方式那一栏点 **Alipay** 图标
2. 勾选"我已阅读并同意服务条款"
3. 点 **Complete Order**
4. 页面跳到支付宝收银台，手机扫码或网页登录付款
5. 付完回到 RackNerd，订单状态变成 Paid

和国内网购扫码没区别。唯一要留意的是结算货币是美元，支付宝按当天汇率折算成人民币扣款，汇率由支付宝的牌价决定，跟 RackNerd 无关。所以同一天不同时段下单，扣款金额可能差几块钱。

有教程作者提到，支付宝订单基本几分钟内自动开通，信用卡订单偶尔会触发风控审核，需要多等一会儿。

## 付款之后：等邮件、连 SSH、做三件安全配置

付款完成 5 到 15 分钟内，注册邮箱会收到两封邮件。一封是订单确认，另一封标题类似 "KVM VPS Login Information"，个别批次可能是 "New VPS Information" 或 "Service Welcome Email"。第二封是关键，里面有：

- 主 IP 地址
- root 密码
- SolusVM 控制面板地址（重装系统、重启、改 rDNS 都在这里）
- SSH 端口，默认 22

连接方式：Windows 用 PuTTY、Xshell 或 Bitvise，Mac 和 Linux 直接开终端输 `ssh root@你的IP`。密码粘贴进去时屏幕不会显示任何字符，这是正常现象，直接回车。

第一次登进去，建议立刻做完这三件事：

1. **改 root 密码**：执行 `passwd`，按提示输入两遍新密码
2. **改 SSH 端口**：编辑 `/etc/ssh/sshd_config`，把 `Port 22` 换成别的端口，重启 sshd 服务
3. **开防火墙**：Ubuntu 用 `ufw`，只放行你实际用到的端口

想更进一步就把密码登录关掉，改成密钥登录。这三步做完，一台默认配置、暴露在公网上的机器才算勉强能看。

## 常见问题

**注册时 Google 验证码加载不出来怎么办？**

换网络环境，或者挂代理后刷新页面重试。这是国内注册 RackNerd 唯一的高频卡点，过了这一关后面不会再有类似障碍。

**买完不满意能退款吗？**

不能。官方条款明确任何产品不支持退款，也没有无理由退货期。取消服务等于停机删数据。这是下单前最该想清楚的一条。

**国内用户选哪个机房？**

圣何塞和洛杉矶 DC-02 是首选，两者都走太平洋直连，延迟通常在一百多毫秒。东海岸机房延迟普遍在 200ms 以上，除非业务本身面向北美东部，否则不建议。买之前可以先找对应机房的测试 IP 在本地 ping 一轮。

**1GB 内存到底够不够？**

跑静态站、轻量代理、开发测试够用。装 WordPress 或者跑数据库就不够，2GB 起步更稳。判断标准很简单：装完你要用的软件之后，`free -m` 里可用内存还剩一半以上，就够。

**能装 Windows 吗？**

可以，但 Windows 系统要额外付月费，几美元到十几美元不等，取决于版本。Linux 系统全部免费。真要跑 Windows 应用，直接买它专门的 Windows VPS 产品线（NVMe SSD 那一条）比自己装更省事。

**IP 被墙了怎么办？**

可以付费换 IP，开工单申请，费用几美元一次。说明情况一般都能处理。
